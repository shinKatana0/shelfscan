# Control prompt fingerprint

The public control check records the prompt version used for local validation.
The control photographs, their names and properties, and every figure measured
from them belong in the untracked local control definition. They are not part
of this repository.

```control-set
[CONTROL-HIRES]
```

```control-set
[CONTROL-LOWRES]
```

## Prompt

The test compares this fingerprint with the assembled detection prompt. A
change means the local control measurements need to be repeated before their
results are used to support a decision.
