# Code of Conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in
full. It is not reproduced here; the linked text is the one that applies.

The short version: be decent. Assume the person on the other side is trying
to help. Disagree about the code, not about each other.

Two things specific to this project:

- **Nobody's photographs go in a public thread.** Issues, pull requests and
  discussions here are about a tool that reads pictures of people's homes.
  Do not post them, do not ask someone else to post theirs, and redact
  paths and filenames that identify a person.
- **Argue with the measurement, not the person who took it.** Claims here
  are expected to name a run. "That was measured differently" is a
  contribution; "you are wrong" without one is not.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@shinKatana0](https://github.com/shinKatana0), by direct message or by
GitHub's own [report abuse](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
flow. Reports are handled confidentially. This is a one-maintainer project:
the maintainer is also the sole moderator, and the escalation path beyond
them is GitHub Support.
