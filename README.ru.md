# ShelfScan

[![CI](https://github.com/shinKatana0/shelfscan/actions/workflows/ci.yml/badge.svg)](https://github.com/shinKatana0/shelfscan/actions/workflows/ci.yml)

Перенесите игры, которые у вас уже есть, в цифровую коллекцию — без
ручного ввода каждой позиции. Сфотографируйте полку, просканируйте игры
на компьютере или прочитайте библиотеку GOG Galaxy. ShelfScan соберёт
результаты для проверки и экспортирует их в Tonkatsu Box или CSV.

Программа занимается распознаванием и экспортом. Сама коллекция
остаётся в приложении, которое вы выберете.

## Сканирование → Проверка → Экспорт

**Сканирование:** выберите фотографии полки или поддерживаемый источник
на компьютере. **Проверка:** поправьте названия и платформы, добавьте
пропущенное. **Экспорт:** сохраните подтверждённые позиции в JSON для
Tonkatsu Box, в прежнем формате `.xcoll` или в CSV.

## Что можно прочитать

- Фотографии игровых полок и коробок: JPEG, PNG, WebP; на Windows также HEIC.
- Установленные игры в папках компьютера, включая метаданные установок GOG,
  если они доступны.
- Библиотеку GOG Galaxy на Windows, в том числе неустановленные игры.
- Папки с медиафайлами, выбранные в приложении. Поддерживаемые имена файлов
  могут также дать строки фильмов, анимации и аниме — проверьте их тип.

Источники можно объединить в одном сканировании. Повторы ShelfScan
сведёт до проверки, но названия и платформы всё равно стоит просмотреть.
Форматы, ограничения и источники подробнее описаны в
[руководстве](doc/guide.md) (на английском).

## Скачать и запустить

На странице [последнего выпуска](https://github.com/shinKatana0/shelfscan/releases/latest)
есть переносимый архив для **Windows x64**. Скачайте
`ShelfScan-win-x64.zip`, полностью распакуйте папку и запустите
`shelfscan_app.exe` внутри неё. Установщик, Dart и Flutter для этого
не нужны.

Для распознавания фотографий выберите модель в настройках. В Windows
по умолчанию выбран локальный Ollama; его нужно установить отдельно.
Загрузите модель командой `ollama pull qwen3-vl:8b-instruct`.
Обычный адрес сервера — `http://localhost:11434`. Затем выберите
фотографии или другие источники, проверьте список и экспортируйте его.

Исходный код Android-приложения есть в репозитории, но готовой сборки
для Android здесь нет. Самостоятельная сборка описана в
[заметках об Android](doc/android-build.md). Для консольной версии и
подробного первого запуска смотрите [руководство](doc/guide.md) (на английском).

## Фотографии и ключи

Для ShelfScan не нужны учётная запись или сервер ShelfScan; собственной
базы коллекции у программы тоже нет. Ключи API в неё не встроены.
Локальный Ollama на вашем Windows-компьютере работает без ключа. Если
указать Ollama в локальной сети, фотографии уйдут на тот компьютер.
При выборе Anthropic или совместимого с OpenAI сервиса фотографии
отправляются ему. Для поиска в каталогах названия могут отправляться
в IGDB или TMDB с вашими ключами. На Windows облачный сервис не
включается сам по себе.

В [руководстве по настройке](doc/guide.md#step-2--choose-a-vision-backend)
описан выбор провайдера; перед отправкой фотографий прочитайте
[раздел о данных](SECURITY.md#your-photographs) (оба документа на английском).

## Tonkatsu Box

ShelfScan распознаёт позиции и даёт вам проверить их. Tonkatsu Box
берёт на себя сопоставление с каталогами, обложки и метаданные.
По умолчанию экспортируется JSON для Custom Cards, совместимый с
Tonkatsu Box v0.45. Если при импорте включён поиск по источникам,
однозначно найденная позиция станет карточкой каталога; неоднозначная
или ненайденная останется пользовательской карточкой. ShelfScan не
угадывает совпадение за вас. Прежний экспорт `.xcoll` тоже доступен.

Формат и варианты импорта разобраны в
[заметке об интеграции с Tonkatsu](doc/integrations/tonkatsu-handoff.md)
(на английском).

### Если открываете CSV в таблице

CSV предназначен для импорта. Excel, LibreOffice и Google Sheets могут
воспринять ячейку, начинающуюся с `=`, `+`, `-` или `@`, как формулу.
ShelfScan сохраняет названия без изменений, чтобы другое приложение
получило исходный текст. Для просмотра файла в таблице импортируйте
его с типом столбцов «Текст», а не открывайте двойным щелчком:
в Excel — *Data → From Text/CSV*, в LibreOffice — диалог Text Import
со снятым флажком *Evaluate formulas*.
